# pedromopi.github.io

Este repositório mantém redirecionamentos do antigo GitHub Pages para
[pedromopi.com](https://pedromopi.com). As páginas HTML preservam o caminho,
os parâmetros de URL e o fragmento. A página `404.html` encaminha caminhos
antigos que não possuem um arquivo próprio.

O site atual fica no projeto local `../site-institucional` e é publicado pela
Cloudflare Pages. Este repositório não contém os arquivos do site atual.
